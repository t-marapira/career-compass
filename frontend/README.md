# Frontend Setup

This frontend is built using **HTML, CSS, JavaScript, and Chart.js**. It provides the user interface for the Career Compass application and communicates with the Express.js backend.

## Prerequisites

Make sure you have the following installed:

* A modern web browser (Chrome, Edge, or Firefox)
* Visual Studio Code (recommended)
* Live Server extension (recommended)

## Installation

Open the frontend folder in Visual Studio Code.

No additional dependencies are required.

## Running the Frontend

Start the application using Live Server or open `index.html` in your browser.

The application will open on your local development server.

## Pages

* Landing Page (`index.html`)
* Login
* Register
* Dashboard
* Assessment
* Results
* Profile

## Technologies Used

* HTML
* CSS
* JavaScript
* Chart.js

## Backend Integration

The frontend connects to the Express.js backend through REST API endpoints to:

* Register users
* Authenticate users
* Submit assessment data
* Retrieve career analysis results
* Display student profile information

## Notes

* Landing page: `index.html`
* Styling is located in the `css` folder.
* JavaScript files are located in the `js` folder.
* Images are stored in the `images` folder.
* Charts are rendered using Chart.js.
